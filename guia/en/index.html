In brief

bicho-dancando is a script kit for anyone making short videos who wants an animal to dance just like a reference video. You provide a video of someone dancing and a phrase describing the animal; the kit paints clothes on the dancer, creates an image of the animal standing upright, and tells Kling (an AI video generator) to copy the moves. At the end, it adds the music and an ending with INEMA.CLUB text. You need a Kling subscription with its command-line tool installed, Python, and ffmpeg.

What it is

The dance comes from the video; the animal comes from your description

Kling has a mode called Motion Control: it takes the movement from a video and applies it to a still image. The kit prepares the video so this mode can accept it, then handles everything in a single call.

💃 Moves copied from the reference

With Motion Control 3.0, the animal follows the reference choreography almost frame by frame, instead of performing an invented dance.

👕 The painted-clothes trick

Kling rejects videos of bodies that look nude. The kit paints a T-shirt and shorts on the dancer, frame by frame, so the video passes.

🎬 Ready to post

You get a vertical 9:16 MP4 with the reference music and a final 4.5 seconds showing "construindo no INEMA.CLUB · baixa o kit" (building on INEMA.CLUB · download the kit), written one letter at a time.

How it works

Five steps, one call

The kit/dancar.sh script handles steps 2 through 5 automatically. You only choose the video and describe the animal.

Requirements

What needs to be installed

Everything runs on your computer except video generation, which is done in Kling through your subscription. Linux or macOS with a terminal.

Kling subscription

The official Kling command-line tool, logged into your account. Login opens the browser and waits for just 5 minutes.

npm i -g @klingai/cli-global
kling login

Python 3 and ffmpeg

To paint the clothes, assemble the ending, and add the music. The pose model (30 MB) downloads automatically the first time.

python3 -m pip install "mediapipe>=0.10" opencv-python pillow
ffmpeg -version

Ending font

Unzip the file downloaded from fonts.google.com/specimen/Montserrat, then run the commands below from inside the unzipped folder. kit/fecho.py uses the Montserrat Black font at this exact path, and only at the very end of the run, after spending credits: check first.

mkdir -p ~/.local/share/fonts
cp static/Montserrat-Black.ttf ~/.local/share/fonts/
ls ~/.local/share/fonts/Montserrat-Black.ttf   # check: the file should be listed

Download the kit:

git clone https://github.com/inematds/bicho-dancando
cd bicho-dancando
Step-by-step user guide

From the reference video to a dancing animal

Run the commands from inside the bicho-dancando folder. The result goes in saida/<nome>/.

1

Choose the reference video

Any MP4 showing a person (or character) dancing full-body with a stationary camera: a video of yourself, recorded on your phone, or downloaded with yt-dlp. The tests used 24 s; the longer the video, the more credits it costs. If the dancer leaves the frame, the animal will too. Save it as ref/video.mp4.

mkdir -p ref   # put the dance video.mp4 here
2

Run everything at once

Provide the video, a short name, and an English description of the animal (Kling understands it better). The script paints the clothes, creates the animal, copies the dance, adds the music, and adds the ending.

kit/dancar.sh ref/video.mp4 capivara "chubby capybara diva with a pink feather boa and red lipstick"
# ready: saida/capivara/capivara-final.mp4
Already have an image of the animal? Pass the file as the fourth argument and the script skips image creation: kit/dancar.sh ref/video.mp4 porco "chubby pink pig" porco.png. A 24 s run costs about 220 credits (4 for the image + 216 for the dance); --poll 2300 in the script is the maximum wait time, in seconds. Each run can take up to about 40 minutes; the terminal waits while Kling works.
3

What the script does behind the scenes

You don't need to run any of this by hand; this is to help you understand what happens (and where credits, Kling subscription currency, are spent).

  • Painted clothes (free, on your computer). kit/vestir.py uses MediaPipe (a Google library that detects the body in an image) to paint a T-shirt and shorts on each frame and saves referencia-vestida.mp4. Without this, Kling rejects the video with AGENT.FileCensorshipUnsafe. A simple line drawing (kit/boneco.py) passes this check, but fails with "No valid characters detected". Painted clothes pass both checks.
  • Standing animal (4 credits for 2 images). If you didn't provide an image, Kling creates a vertical 9:16 full-body photo of the animal standing on two legs (bicho.png). If you use your own image, choose an animal in a human-like pose, with its arms and legs clearly away from its body: with the "standing still" capybara, its legs close to its body, Kling returned "No valid characters detected in the image" (without charging); the same capybara in a dance pose worked.
  • Copied dance (216 credits for 24 s at 720p). Motion Control 3.0 applies the movement from the dressed reference to the animal (--motionDirection motion_direction = follow the video's movement). The prompt asks for "natural fur and skin with no clothes" so the painted clothes don't transfer to the animal. Cost increases with the reference video's duration.
  • Music and ending (free). ffmpeg combines the reference audio, and kit/fecho.py darkens the final 4.5 s and writes "construindo no / INEMA.CLUB / baixa o kit" (building on / INEMA.CLUB / download the kit), one letter at a time, in yellow and white.

Want to paint the clothes only, to see how it looks before spending credits?

python3 kit/vestir.py ref/video.mp4 vestida.mp4
4

Add an ending to any of your videos

The ending also runs on its own, on any vertical 720×1280 video. The last number is the ending duration in seconds.

python3 kit/fecho.py meu-video.mp4 meu-video-fecho.mp4 4.5
5

Check before posting

Create a frame sheet (12 video stills in one image) and check the face, background, and hands (paws). If anything looks off, run the same command from step 2 again: the script reuses referencia-vestida.mp4 already in saida/<nome>/. If it looks good, post wherever you like: Reels, TikTok, Shorts.

ffmpeg -i saida/capivara/capivara-final.mp4 -vf "fps=1/2,scale=200:-1,tile=6x2" -frames:v 1 folha.jpg   # frame sheet
Examples

Pig, capybara, and kitten

All three animals dancing to the same routine, each for 216 credits. Click an image to watch the video on YouTube.

Free variant with Agnes

kit/agnes_poses.py creates the pig with Agnes: 1 anchor image + 3 poses derived from it (so it's the same animal) + 3 clips of 8 s transitioning from pose to pose. The moves are free-form, not copied. In one of the 3 clips, the scene drifted (the background changed and the animal turned its back): check the clips and redo only the one that looks off. Requires the videos-agnes project cloned into ~/projetos/videos-agnes and an Agnes AI API key in the AGNES_API_KEY variable (the videos-agnes guide explains how to get one).

Limitations

What we know can go wrong

Measured in the kit's tests.

  • Kling decides what counts as a character. A simple line drawing doesn't count; a photorealistic animal standing upright does.
  • The animal image pose matters. An animal standing still, with its legs close to its body, returned "No valid characters detected in the image" (without charging). Use an image with arms and legs away from the body, in a dance pose.
  • The framing comes from the reference. If the dancer leaves the frame, the animal will too. Prefer a stationary camera and a full-body shot.
  • The CLI login expires. kling login opens the browser and waits only 5 minutes for you to return.
